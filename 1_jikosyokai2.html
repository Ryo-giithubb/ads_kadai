AID 1ヶ月目課題 ／ Skill Report

パーソナル図解スキル
— 工夫まとめ —

小野良介（COLORFUL 昱景設計）が設計した、建築・内装設計業務のための図解生成スキル

このスキルの仕組み
STEP 1
情報を入力
目的・内容・読者をテンプレートに記入
→
STEP 2
AIが生成
固定デザイン要件でHTML図解を自動作成
→
STEP 3
即共有
1ファイルのHTMLをそのまま送付・公開
3つの工夫ポイント
🎨

デザインを固定して迷いをゼロに

背景色・メインカラー・フォント・角丸・余白をスキルに埋め込み固定。毎回AIが勝手にデザインを変えないようにすることで、ブランドの一貫性を担保。

📱

外部ライブラリなし・1ファイル完結

vanilla HTML + CSS + JS のみ。ライブラリ読み込みエラーがなく、HTMLファイル1つをメールに添付したりDropboxで共有するだけで相手がすぐ見られる。

🌏

中国語圏クライアントを想定した設計

読者欄に「中国語圏クライアント」と指定すれば日中バイリンガル対応の図解が出力される。設計事務所の実際の業務フローに即した仕様。

プロンプトテンプレート（抜粋）
Prompt Template
【図解の目的】
クライアントへの概念方案説明

【伝えたい内容】
- パンチングメタルの素材特性
- 採用プロジェクト実績
- 南京プロジェクトでの課題と解決

【デザイン要件（固定）】
背景: #fbfbfa ／ アクセント: #2e76ab
カード型・角丸14px・スマホ対応
外部ライブラリ不使用・1ファイル完結
スキル導入 Before / After
Before
  • 毎回プロンプトをゼロから書く
  • デザインがバラバラになる
  • 何度も修正指示が必要
  • 中国語対応を毎回指示し忘れる
After
  • テンプレートに埋めるだけ
  • 毎回同じブランドデザイン
  • 一発でほぼ完成形が出る
  • バイリンガル対応が自動化

スキルを育てる中で気づいたこと

  • 情報は5個以内に絞ると図解がすっきりする
  • 「相手が何を知りたいか」から逆算して項目を選ぶ
  • ドラフトを出させてから手直しする方が圧倒的に速い
  • デザイン要件を固定するとAIが「考えること」に集中できる
